# Temporary demo input review

This local test project copies the add-on and demo from `../capacity-aware-npc-transport/review-candidate-verified-2026-11-26/`. Three scripts under `tests/` adapt its original viewport input test to 640×480, 800×600 and 1152×648, and assert the viewport size and that the tested controls fit its bounds before testing. They inject mouse clicks for pause, save and load, a focused keyboard action for resume, focus traversal from Save to Load, and focused keyboard activation of Load. All three sizes passed on standard Godot 4.4.1, 4.5.1 and 4.7.2 on Windows, with the known root-certificate-store warning.

Example: `godot --headless --path <this-folder> --script res://tests/test_demo_input_640x480.gd`, using isolated user data. These are synthetic events, not physical-device, accessibility, DPI-scaling, visual legibility or other-platform acceptance. They exercise the development demo, which is not included in the smaller install review.


A 150% Godot content-scale test initially found Save and Load outside the visible viewport. The development demo was updated to wrap controls, put them before the status, scale the status font at narrow widths, wrap the message and permit the details panel to be collapsed. At a 960×720 window with a 640×480 content-scale setting and factor 1.5, the final scaled input check verified control and label bounds, simulated mouse/keyboard actions and hide/show behavior on standard 4.4.1, 4.5.1 and 4.7.2. A separate scaled state-change check also passed on those versions after the demo advanced and after a service message changed. Hidden 4.7.2 expanded and compact captures were inspected. These are not native OS DPI or physical-input/accessibility tests. The fixed demo restores the later dark backdrop present in the working development source; the prior `review-candidate-verified-2026-11-26` demo did not contain that backdrop.
