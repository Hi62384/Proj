# GDM-003 cyclic import follow-up — 2026-11-18

The project plan calls for a cyclic-import negative case. Two owned x64 DLLs were built so `root.dll` imports `middle.dll` and `middle.dll` imports `root.dll`; `dumpbin /imports` and the local PE probe independently showed both edges. Their functions recurse indefinitely, so the cyclic DLLs were **not loaded or executed**. The fixture is for static inspection only.

The trusted-fixture spike terminated and now reports `extension.dll → root.dll → middle.dll → root.dll` as a static import cycle with runtime behavior unknown. It does not call the cycle a runtime failure. In the tested Dependencies 1.11.1 JSON chain, the repeated resolved root path appeared and the repeated node had no children; the command returned 0. The original small JSON helper did not call attention to the cycle, so it was extended to flag a repeated resolved fixture path as unknown and return 3 when there is no missing-import finding. This helper remains fixture-specific and does not prove general cycle detection or loader behavior.

An initial implementation reused a variable name that was also used for descriptor parsing; the integration suite caught errors in multi-descriptor cases. The variable was corrected, and the suite passed on rerun. A fresh full matrix rebuild produced the cyclic binaries and passed eight PE tests, twenty-two fixture integration tests, three DIY-helper tests and two builder-safety tests. The full rebuild began before the additional data-only packaging change, so that particular temporary cycle copy may contain a game executable and must not be run. The current builder omits the executable and PCK from the cycle variant; its copy helper was separately exercised in a fresh directory and confirmed to omit both. The data-only copy was inspected successfully without loading it.

The free workflow exposes the repeated path and the corrected helper can label it unknown; this single case does not demonstrate a material product advantage or establish general parity. The conditional feasibility gate, unvalidated commercial state and trusted-input-only limitation remain. No spending, customer contact, outreach, publication or sale occurred.
