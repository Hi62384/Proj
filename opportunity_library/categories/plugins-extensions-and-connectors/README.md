## Commercial thesis

Build the smallest missing step in an existing workflow. Permission minimization and documented export paths create trust; read-only adapters reduce initial risk.

**Principal obstacle:** Platform changes and rejected permissions can break distribution. A source licence may permit internal use but not paid embedding or resale.

These are screened concepts, not verified profitable businesses. Current category/platform sources establish alternatives and constraints, not willingness to pay for our exact products. Test-price ranges, effort and scores are unmeasured planning assumptions.
