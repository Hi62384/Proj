# What to try first—and what not to start
No ranking is a probability of success. All exact offers remain unvalidated.

## Primary options
| Priority | Project | Why consider it | Condition before offering |
|---|---|---|---|
| First small diagnostic/repair | AWA-005 — form field mapping rescue | Specific visible failure, limited fields, existing tools | Reproduce a permitted example and validate skill; no full rebuild |
| First bounded implementation | AWA-001 — form-to-CRM starter | Comparable implementation requests; concrete result | Customer owns the stack, native alternative inadequate, scoped quote covers all time |
| Alternative diagnostic | AWA-007 — broken webhook diagnostic | Sell an investigation before accepting unknown repair work | Buyer understands that diagnosis, not a guaranteed fix, is purchased |
| Existing-work takeover | AWA-012 — unfinished workflow assessment | Avoids an unlimited rescue promise | Read-only access and named acceptance owner; no fixed-price full completion before assessment |
| New adjacent test | AWA-122 — approved Sheets-to-Docs report assembly | Relevant request signal, deterministic output and existing tools | Template is complete, no regulated assessment, quota/layout cases demonstrated |
| Existing-asset sales test | EX-001 / EX-002 | Products and store already exist; no new build needed | Truthful compatibility/free-alternative comparison and a permission-appropriate channel |

Run one service test and optionally one small existing-product promotion test, not all six at once. Stop each at its own work/cash gate; the portfolio still retains the broad long-term options. The product test may produce no income; zero setup cash does not imply strong demand.

## Six additional candidates
AWA-121 internal Apps Script trigger diagnosis; AWA-122 approved document assembly; AWA-123 digital-download delivery QA; AWA-124 opt-in welcome/suppression setup; AWA-125 one purchase-event acceptance test; AWA-126 one measured credit-reduction retrofit.

These are six additional scoped service offers, not six validated businesses. AWA-126 is an explicit follow-on to AWA-095; do not count its client as a second independent market. AWA-125 needs demonstrable analytics/consent competence and is not a first-sales recommendation. AWA-121's related job has low advertised rates, so a sensible quote still needs buyer proof. AWA-123/124 are adjacent to a broader funnel request, not directly proven standalone purchases.

## Defer or reject for this objective
Generic AI-content machines with large scope and low budgets; broad CRM rescues priced before diagnosis; migrations justified only by a cheap advertised plan; owner-hosted client production; 24/7 retainers; security/compliance certifications; production token-vault or multi-tenant software under an assumed CAD100 total cost; broad paid ads for the CA$9/CA$15 products before conversion economics exist; purchased lists or unsolicited automated outreach.

The 58 components remain parent deliverables, not independent products. The 12 download/software candidates stay demand-gated. Existing tools and archives remain preserved, not commercialized by default. A proposed customer price is accepted only when a real buyer agrees and the measured work fits—not because the spreadsheet says it should.
