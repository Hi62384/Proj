# One-hour preparation checklist: business #1

- [ ] Double-click `Start_Autopilot.cmd`; local browser dashboard opens.
- [ ] Click **Prepare first sales pack**; read `first_reporting_business/00_START_HERE.md`.
- [ ] Unzip `SYNTHETIC_REPORT_DEMONSTRATION.zip` somewhere private; open `results/report.html`.
- [ ] Confirm the demo is **synthetic**, not prior customer work; capture an honest screenshot.
- [ ] Decide whether one freelancer platform can handle the first sale without any direct payment infrastructure.
- [ ] Finish a truthful seller profile yourself (KYC and payout identity cannot be delegated).
- [ ] Prepare an individually reviewed fixed-scope offer at a market-tested price; CAD 299 is only the initial hypothesis.
- [ ] Identify five current matching buyer requests using permitted means; compare actual competing offers and budgets.
- [ ] Send no proposal until checked for requirements, skill fit, fees and platform restrictions.
- [ ] Before accepting a job: get authority for redacted data, exact input/output, accepted price, delivery date and funded milestone.
- [ ] Use `report-preflight` and `report-package` for the approved work. Verify against the source; no direct web uploads or emailing from the CLI.
- [ ] Deliver through permitted channel, reconcile real fees and settlement, record all owner time.
- [ ] If no meaningful buyer conversations emerge, revise acquisition/offer. Do not launch many unvalidated storefronts.

## After two accepted paid jobs

- [ ] Decide which input formats really recur; extract only reusable, client-owned/authorized code and original work.
- [ ] Improve one repeatable acquisition channel and fix source errors.
- [ ] Consider bounded maintenance only if buyers demonstrate repeat-use demand.
- [ ] Prepare **different industry** offers with the one-click factory; test actual buyer interest in parallel, not hundreds of deployments.
- [ ] Add direct checkout/fulfillment integrations only after account approval, secure webhook tests and spending limits.

**No claim of success:** This toolkit is code, mockups and operational templates. It does not create sales or guarantee a first client.

## Quick command for the seller who wants to avoid terminal setup

The fastest route does not require n8n, Stripe, hosting or any installed AI agent. One Windows double-click opens the local dashboard; **Prepare first sales pack** produces a downloadable-in-File-Explorer demonstration ZIP and copy-ready listing. Your only essential account for the initial marketplace test is an appropriate freelancer account, whose identity and payout verification you must complete yourself.
