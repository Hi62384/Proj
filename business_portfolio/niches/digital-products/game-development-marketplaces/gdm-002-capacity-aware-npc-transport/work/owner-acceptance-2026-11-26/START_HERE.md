# GDM-002 hands-on check

This is a local test project. Launching the files below opens visible Godot windows only when you choose to double-click them. Its user data and test saves are kept in this folder. Nothing is published.

1. Double-click `START_DEMO.cmd`. In the demo, click **Pause / resume** twice. Click **Save**, then **Load**; the message should say the save was loaded. Try **Disable B-fast** and **Enable B-fast**; if the demo says an action is only available between ticks, try again.
2. Use your keyboard to move focus with Tab and activate controls with Enter or Space. Check that you can see which control has focus. Try **Hide details** and **Show details**.
3. Resize the demo window smaller. Check that controls and text remain readable and that hiding details makes the scene easier to see. You do not need to change your computer's display scaling. Close the demo when finished.
4. Double-click `START_MARKER_EDITOR.cmd`. In Godot's scene tree, select and deselect **TransitStop**. Check that the cyan diamond marker is visible and that selecting the node shows **Stop Id: hub** in the Inspector. The marker is visual only. Close the editor when finished.
5. Tell Codex which steps passed and describe anything that was hard to use or did not work. Do not include private information in screenshots or logs.

This check covers your actual mouse/keyboard and display. It is not a screen-reader or full accessibility certification, and it does not approve publication or spending.
