# Completed projects

Each `ID.json` in this directory is a self-contained, public, durable completion receipt created when an agent verifiably completes Phase 6 marketing with verified release and public marketing evidence. It remains here even if the original project folder is removed. The Portfolio Manager displays these records but does not offer deletion. Delete or correct a receipt only through the filesystem, reviewing its evidence and links first. Never store private user or payment data here.

A niche or subniche deletion moves its source subtree into recovery storage and leaves these receipts intact. Completion does not imply sales or profit.
