RECALCULATING, WHEN YOU CHOOSE
Requires an already available Node.js runtime and Python 3. No package downloads are needed for the model, independent audit or report builder. From this folder:
1. Edit assumptions.json deliberately, retaining valid JSON.
2. Run: node financial_model.mjs
3. Run: python audit_financial_model.py
4. Run: python build_deliverables.py
The model overwrites only its financial result/summary files. The audit writes financial_audit.json. The builder overwrites the report and local dashboard using the included source data/fragments. Make a copy first if you want to retain earlier scenarios. These scripts do not contact services, launch businesses or transmit data. A changed strategy or launch sequence needs changes to the model logic as well as assumptions where applicable.

Do not run a command on the user's computer without the necessary authorization. These instructions are provided for later voluntary use; the calculations for this edition were performed in a separate cloud workspace.

MODEL DEFINITIONS
Pretax operating net: gross revenue less refunds, disputed revenue, fees and modeled cash expenses. Owner wages and personal taxes are not deducted.
Economic net: pretax net less all owner time at illustrative CAD25/hour.
Tax reserve: a separate 30% planning cash target, not a calculated tax liability.
Ordinary cash: settled available balance after expenses and reserve transfers. Sales awaiting payout are receivables, not spendable cash.
No-sales/base/upside figures in the opportunity database are simplified conditional unit models. They are not the combined portfolio forecast and must not be added across candidates.
